# Product

## Register

product

## Platform

web

## Users

**Primary:** Hotel staff (admins, receptionists, housekeepers) managing daily operations — check-ins, room assignments, pricing, analytics, housekeeping tasks. They use this system all day, every day, across multiple screens and workflows.

**Secondary:** Hotel guests booking rooms, checking in, managing their stay, and accessing their dashboard. They interact with a subset of the system, typically once per stay.

## Product Purpose

A modern hotel property management system (PMS) that replaces legacy tools like Cloudbeds and Hotelogix with a cleaner, faster, more intuitive interface. It handles the full lifecycle: room inventory, booking, check-in/out, housekeeping, pricing, analytics, and guest management — all in one system.

Success looks like staff completing daily workflows faster than with their previous PMS, guests completing bookings without friction, and the system feeling effortless rather than enterprise-heavy.

## Positioning

Modern UX that makes hotel management feel as clean and fast as the best consumer apps — no legacy cruft, no training manual required.

## Brand Personality

Minimal, professional confidence. The interface should feel sharp, efficient, and quietly assured — like a well-run boutique hotel where everything just works. Not loud, not decorative, not trying too hard.

## Anti-references

- **Generic PMS software** (Cloudbeds, Hotelogix, eZee): Overwhelming dashboards, cramped layouts, tiny fonts, enterprise-heavy UIs with 50 visible options per screen. The opposite of focused.
- **Luxury brand marketing sites**: Overly decorative, slow, form-over-function. This is a tool, not a brochure.
- **SaaS dashboard templates**: Generic cards with icon + heading + text repeated endlessly, gradient accents, hero-metric templates.

## Design Principles

1. **Effortless clarity** — Every screen should make the next action obvious. No hunting, no training.
2. **Professional calm** — The interface should reduce cognitive load, not add to it. Staff use this under pressure.
3. **Minimal by default, detailed on demand** — Show only what's needed now. Let users drill deeper when they choose to.
4. **Consistent rhythm** — Shared patterns across guest and staff surfaces create a unified system feel.

## Accessibility & Inclusion

Target WCAG 2.1 AA. Support for reduced motion, keyboard navigation throughout, and sufficient contrast ratios. Staff use this all day — eye strain and accessibility aren't nice-to-haves.
